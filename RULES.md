# Project Rules

1. **Follow Instructions Exactly:** Always create what is mentioned in the instructions. Do not overengineer.
2. **Break Down Complexity:** Dissect problems into smaller, manageable tasks.
3. **Consistent Design:** Always use the `DESIGN.md` file as the source of truth for all UI decisions.
4. **Git Etiquette:** Do not commit or push `.md` files unless explicitly specified.
